# AHMED AI

مساعد كتابة ذكي باللهجة المصرية لإعداد مسودات منشورات وتعليقات وردود ومراجعتها قبل النشر.

**تنبيه:** لا توجد واجهة Meta رسمية عامة لأتمتة النشر والرد من الحسابات الشخصية. هذا الإصدار لا يطلب كلمة مرور فيسبوك ولا يتحكم في الحساب؛ يجهز مسودات للنسخ والمراجعة. يمكن لاحقًا إضافة تكامل رسمي لصفحات Facebook عند توفر صلاحيات Meta.

## التشغيل
1. Python 3.11+
2. انسخ `env.sample` إلى `.env` وضع مفتاح مزود AI المتوافق مع OpenAI.
3. ثبّت الحزم: `pip install -r requirements.txt`
4. شغّل: `uvicorn app.main:app --reload`
5. افتح `http://127.0.0.1:8000`

لا ترفع مفاتيح API أو ملف `.env` إلى GitHub.
